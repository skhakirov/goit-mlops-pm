# Docker Image Review: технічний PM-review Docker-рішення

Checklist перевірки рішення команди за чотирма блоками: Dockerfile, залежності, запуск inference і відтворюваність. Кожен пункт містить очікуваний результат і спосіб перевірки; колонка AC посилається на `acceptance_criteria.md`.

**Поточний стан:** команда ще не здала артефакти, тому всі статуси — `TBD`. Статус заповнюється під час review: «так», «ні» або «відхилення погоджено» з коментарем.

## Висновок review

Зараз перевірено 0 пунктів із 20: артефакти ще не здані. Slim-образ приймається й передається далі (registry → staging) лише тоді, коли всі 20 пунктів мають статус «так» або «відхилення погоджено». Найважливіший — блок 4.4: якщо поведінка моделі в slim відрізняється від fat, оптимізація не приймається незалежно від виграшу в розмірі.
